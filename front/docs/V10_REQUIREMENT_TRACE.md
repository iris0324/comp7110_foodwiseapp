## 高風險／不能假裝完成

- Supabase Email/Google Auth、Guest 跨帳號轉移、RLS 不在本次純前端版本內。
- 真實商品照片的任意物件辨識與一般收據 OCR 尚需後端服務。
- `jsQR`、`ZXing-JS` 尚未離線隨包；有支援原生 `BarcodeDetector` 的瀏覽器可嘗試 QR，其他環境須提供相依函式庫。
- 背景手機通知需要 Web Push / Service Worker 與後端排程，不能以本機提示冒充。
- 已舊有帳號或 Guest 的跨裝置資料合併尚未提供。
